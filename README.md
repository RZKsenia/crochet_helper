# 🧶 Вязальный помощник | Crochet Helper

> Одностраничное веб-приложение для удобной работы со схемами вязания крючком.  
> Загружайте схемы, отмечайте петли, считайте ряды и сохраняйте прогресс — всё работает прямо в браузере, без сервера и интернета.

## ✨ Ключевые возможности

| 🧵 Работа со схемой | 📊 Учёт и расчёты | 💾 Прогресс и данные |
|-------------------|------------------|---------------------|
| Загрузка любой картинки со схемой | Счётчик рядов с кнопкой `✅ Ряд закончен` | Сохранение/загрузка проекта в `.json` |
| Палитра из 12 типовых петель (ВП, СБН, С1Н–С3Н, Приб., Уб., Кластер, Пышный, Попкорн) | Калькулятор размеров по плотности вязания (пет/ряд на 10 см) | Автосохранение в `localStorage` каждые 30 сек |
| Настройка цвета отметок + кастомная палитра с пипеткой | Подсчёт количества каждой петли на схеме | Заметки, привязанные к конкретным рядам |
| Включаемая сетка для удобства подсчёта | Динамическая статистика проекта | Экспорт и импорт без потери координат |
| Масштабирование колёсиком + перетаскивание схемы | | Полная офлайн-работа |

## 🚀 Быстрый старт

1. Скачайте файл Вязальный помощник.html, откройте его в браузере - наслаждайтесь!
